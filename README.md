# CodeStore

## Описание

CodeStore - это веб-приложение предназначенное для хранения плагинов и примеров кода для последующей продажи.

## Использование

1. Для запуска приложения достаточно прописать в терминале следующий код:
   ```
   python config/manage.py runserver
   ```

2. В проекте есть приложение catalog, которое отвечает за обработку GET и POST запросов к основным веб-страницам.
